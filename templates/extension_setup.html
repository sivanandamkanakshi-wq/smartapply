Setup Instructions

  1. Download the extension folder from SmartApply (provided separately) and unzip it somewhere permanent.
  2. Open Chrome and go to chrome://extensions
  3. Turn on Developer mode (top-right toggle)
  4. Click Load unpacked and select the unzipped extension folder
  5. Click the SmartApply icon in your Chrome toolbar, paste your API token above, and click Save
  6. Go to any job application form, click the floating ⚡ Auto Fill button that appears, and review the filled fields before submitting
