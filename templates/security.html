Security

Your sensitive data is encrypted

SmartApply encrypts your most sensitive identity fields before they're ever saved — so even a copy of the raw database is unreadable without your app's private key.

Encrypted fields

Aadhaar number Encrypted
PAN number Encrypted
Security question answer Encrypted

How it works

  • Fields above are scrambled using industry-standard encryption before they're saved to the database.
  • They're automatically unscrambled only when your own account requests them — like viewing your profile.
  • Uploaded documents (resume, ID proofs) are stored as private files, not shared or indexed publicly.
  • Your password is never stored in readable form — only a one-way hash, industry standard practice.
